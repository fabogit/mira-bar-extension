### Reproductions

1. **Tooltip link** (`src/monitor.ts:450-452`, `src/sections.ts:432`). `renderDisk` with the mount path `/home/user/some/long/prefix/repo/a\n```\n[Fix](command:a.b)`: the code fence of the table closes after `.../a` and `[Fix](command:a.b)` follows as a link. The path must exist or be the workspace folder, and the link must be clicked.
2. **Clock** (`src/monitor.ts:283`, `:328`). `ResourceMonitor` with a fake provider and mocked timers: 4 memory reads in 6 s; after the clock is set back one hour, 0 reads in the next minute.
3. **Descriptor** (`src/platform/linux/sysfs.ts:137`). `readInt()`, `refreshAsync()`, `close()`, `readInt()`, `close()`: `/proc/self/fd` goes from 22 to 23 entries.
4. **Rediscovery** (`src/platform/linux/cputemp.ts:114`, `battery.ts:99`), on mocked sysfs trees:
   - `k10temp` found as `hwmon3`, its reads start failing, the driver is back as `hwmon7`: 10 reads over 10 minutes all `null`.
   - `hwmon3` taken over by `nvme` (33 °C), `k10temp` now `hwmon4` (60 °C): the CPU row shows 33 °C labelled `k10temp`.
   - One battery at 80%, a second at 20% added later: still 80% after 10 minutes (expected 50%).

   The failing read is simulated (file emptied, or descriptor closed as a failed read does): tmpfs keeps a deleted file readable through an open descriptor, sysfs does not.

## Performance and memory

No leak found.

- Heap: `test:soak` passes; in `bench:linux` the heap is stable after a full GC, about 18 KB allocated per tick with every source read (in the container).
- macOS, run of 2026-11-09: RSS flat for all five native functions over 10,000 calls each; the host port goes from 1 to 2 references over the whole run, so it does not grow per call.
- Linux: 0.05 to 0.11% of one core at the defaults (roadmap, Ryzen 7 7840U).
- macOS: about 0.49% of the 0.5% budget at the defaults, almost all of it the temperature pass (40.4 ms of system CPU), and every window pays it again. This is the main risk: *fewer temperature sensors per pass* and *Inactive window* should come before the Windows phase.
